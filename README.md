# Entre Nous

Application de pronostics et jeux entre amis autour du football.

## Développement

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Refonte visuelle en cours

La branche `chatgpt/visual-redesign-home` contient une refonte visuelle mobile de l'accueil. Elle reste séparée de `main` tant qu'elle n'a pas été validée sur téléphone.
